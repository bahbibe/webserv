webserv

This page is being served by the project itself - a from-scratch HTTP/1.1 + HTTPS server, no framework, no external HTTP library.

Try the moving parts:
  • /cgi-bin/info.py - a live CGI script, run over a real non-blocking pipe (not a temp file)
  • /uploads/ - directory autoindex (upload a file with curl -F file=@yourfile http://127.0.0.1:8090/uploads and refresh)
  • /missing-page - a 404 served from a custom error page

Upload something from the command line:

curl -F "file=@somefile.txt" http://127.0.0.1:8090/uploads

Config used for this instance: conf/default.conf. See the README for the full directive reference.
